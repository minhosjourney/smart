RC카 방향 기준 🟡 FRONT = 카메라가 없는 쪽   /   🔵 BACK = 카메라가 장착된 쪽
사용 순서: ① 출발지점 지정을 누르고 웹캠 화면 클릭 → ② 도착지점 지정을 누르고 화면 클릭 → ③ 경로 계산 → ④ 화면에 표시된 경로를 확인한 뒤 실행.
RC카 위치/방향은 카메라가 없는 쪽=노란 FRONT 마커, 카메라가 있는 쪽=파란 BACK 마커로 인식합니다. 경로 계산만 눌렀을 때는 RC카가 움직이지 않습니다.
인증키: 입력한 키는 로컬 server.py로 POST 전송됩니다. "이 브라우저에 저장"을 선택한 경우에만 localStorage에 저장됩니다.
